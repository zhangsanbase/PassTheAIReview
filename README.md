# Interview Desk / 面试参考工作台

面向 Windows 10/11 x64 的个人面试学习与模拟练习桌面工具，基于 Electron + 原生 HTML/CSS/JavaScript。支持系统音频/麦克风采集 → 阿里云百炼实时转写 → DeepSeek（或任意 OpenAI 兼容接口）流式参考回答。

> **定位与协议说明**：本项目定位为个人口语练习、模拟面试准备与复盘参考工具，请勿将其用于违反平台或考试/面试规则的场景。项目采用 **[PolyForm Noncommercial License 1.0.0](LICENSE)**（非商业许可）：允许免费用于个人学习、研究与非商业分享修改，**禁止任何商业用途**。

## 一键启动与打包

### 方式 A：直接使用 Windows 便携版（推荐普通用户）
从 GitHub Releases 页面下载 `InterviewDesk-<版本>-win-x64.zip` 解压后，直接双击 `InterviewDesk.exe` 即可一键启动，无需安装 Node.js。

- **安全提示**：便携版打包产物由 GitHub Actions 在干净环境自动编译并附带 `SHA256SUMS.txt` 校验文件。因未使用付费商业代码签名证书，首次运行 Windows Defender SmartScreen 可能弹出「未知发布者」提示，确认校验值无误后点击「更多信息 → 仍要运行」即可。

本地自行打包命令（在已安装依赖的环境下执行）：

```powershell
npm run build:win
```

执行后会在 `dist/` 目录生成可直接运行的 `InterviewDesk-0.1.0-win-x64/` 文件夹与 `InterviewDesk-0.1.0-win-x64.zip` 压缩包。

### 方式 B：从源码运行（需要 Node.js 22+）
需要 Windows 10/11 x64、Node.js 22 或以上及可连接服务的网络。可直接双击 `start.cmd` 一键自动安装依赖并启动（已处理 IDE 终端 `ELECTRON_RUN_AS_NODE` 环境变量冲突），或在命令行执行：

```powershell
npm install
npm start
```

初次安装 Electron 可能需要下载 Chromium 运行文件。

应用具有单实例保护：第一次启动打开工作台，再次双击 `start.cmd`、`InterviewDesk.exe` 或执行 `npm start` 会显示并聚焦已有窗口；窗口最小化时会恢复，不重新启动监听或手机音频。检测由Electron主进程执行，而非按通用electron.exe进程名判断，避免误判其他Electron软件。测试使用单独配置目录及单独实例锁，不影响正常工作台。

## 首次配置

点击右上角「设置」：

1. **回答服务（DeepSeek / OpenAI 兼容）**：
   - **接口地址（Base URL）**：留空默认使用 DeepSeek 官方接口（`https://api.deepseek.com`）；也可填写兼容 OpenAI 格式的接口地址（如 `https://api.openai.com/v1` 或本地 `http://localhost:11434/v1`）。
   - **API Key**：填写对应接口密钥（使用本地无鉴权兼容服务时可留空）。
   - **模型名称**：默认 `deepseek-flash`，如使用其他兼容服务或模型请改为对应可用模型 ID。
2. **阿里云百炼实时语音**：填写 **API Key、业务空间 ID（Workspace ID）和对应地域**，默认语音模型为 `fun-asr-realtime`（留空即使用默认，也可在设置中自定义语音模型名称），并确保账号已开通对应模型权限。北京、新加坡的密钥、业务空间和服务权限需要匹配。两项服务分别计费。
3. **个人背景**：默认为空，可按需粘贴个人经历、项目职责与目标岗位要求。无需提供资料也能回答知识题。
4. 点击「保存设置」。密钥输入留空表示保留；用对应勾选框清除旧密钥。

服务说明：[DeepSeek](https://api-docs.deepseek.com/api/create-chat-completion/) · [百炼 WebSocket](https://help.aliyun.com/zh/model-studio/fun-asr-realtime-websocket-api)。

## 使用

界面采用紧凑双层顶部控制栏：上层集中了监听、声音来源、自动/手动分题、手机音频、置顶与设置；下层精简保留核心鼠标操作按钮（`＋ 新问题`、`立即回答`、`合并并回答`、`停止生成`、`展开回答 ↗`），下方左侧为历史列表及 `↶ 撤销` / `↓ 导出`，主体区域完整留给当前提问与回答阅读。宽窗口时左侧输入、右侧回答，回答区域占更大宽度；较窄窗口自动上下排列。所有业务行为与防误触保护不变。

### 手机声音转到电脑

1. 安装官方 scrcpy：`winget install --exact Genymobile.scrcpy`（包含ADB）。软件会在PATH和当前用户的WinGet安装目录查找，无需手填路径。
2. 手机需要Android 11以上，用USB数据线连接电脑，打开USB调试，并在手机上允许此电脑。这里只选择USB设备；有多台USB调试设备时请只保留一台。
3. 有线耳机接电脑，并设置为Windows默认输出设备。点击顶部 **「手机音频 · 开启」**，等待提示转发进程启动；在手机播放语音检查是否能从电脑耳机听到。
4. 软件声音来源选择 **「系统声音 · 对方发言」**，再点 **「开始监听」** 进行转写。转发与识别是两个独立开关。
5. 再点 **「手机音频 · 停止」** 结束转发。手机未授权、没连接、系统太旧或运行中断开时有提示；转发进程运行不代表所有手机App都能被捕获，需在具体App测试声音和回答录音。

按钮只启动无视频、无手机控制、无录制的scrcpy音频转发。停止或退出软件只结束本软件拥有的转发进程，不关闭ADB服务或其他独立启动的scrcpy；手动运行的旧转发进程请先自行退出，避免重复转发。它不把电脑耳麦的麦克风传回手机，手机面试的录音仍需单独验证。

- **先测试文字问答**：在当前提问中输入问题，点击「立即回答」。只需要 DeepSeek 配置即可使用。
- 顶部「声音来源」可选 **系统声音 · 对方发言** 或 **麦克风 · 我的说话**，选项会保存。麦克风模式使用 Windows 默认输入设备（在系统声音设置中切换内置/耳机麦克风），只申请音频，不申请画面。切换来源会停止当前采集，再点击「开始监听」使用新来源；同一时间采集一种来源。
- 麦克风识别同样使用百炼实时转写及现有中英文回答规则。缺少百炼配置时只做本地音量检测，不上传声音。自动回答开启时，自己说的话也会触发生成；只想转写时可关闭自动回答。麦克风声音不会被本软件回放到耳机。
- 将耳机设置为 **Windows 默认播放设备**，会议软件也使用同一设备。点击「开始监听」。首版采集系统播放声音而非麦克风，同一默认设备的音乐、通知声音也可能进入转写。
- 尚未配置百炼时，「开始监听」进入**仅本地音量检测**，无需 API、不上传音频。可在 VMware 内播放语音，检查音量条是否变化。虚拟机声音需要经宿主机默认播放设备输出；USB 声卡直接透传给虚拟机的路由不在当前宿主机回环采集范围内。配置百炼并重新开始后启用转写。
- 自动回答依据静音断句，不保证每次停顿都代表完整问题。默认 800 ms 静音 + 200 ms 合并等待；长问题容易截断时，可提高参数或关闭自动回答，由顶部按钮手动提交。
- 界面已移除全部键盘快捷键（含全局恢复热键）与冗余锁定按钮，问题输入框默认可直接编辑，所有操作均通过顶部与左侧按钮以鼠标完成；右上角可切换深色/浅色模式并开启置顶。
- 点击顶部「＋ 新问题」会新建空白问题并聚焦输入框，历史问答保留；点击「立即回答」支持首次生成或编辑后直接重新生成。
- 「合并并回答」将当前编辑后的文字与上一题拼成一个新问题并立即生成答案，同时保留原记录，适合长问题被停顿拆开时使用；连续合并会跳过已包含的原始问题，避免重复拼接；没有上一题时不可用。
- 历史列表每题旁的「×」可删除问题及对应参考答案；删除正在生成的问题会停止该请求。左侧底部「↶ 撤销」逐次恢复最近删除的记录（仅限本次会话）；删除的题目不参与后续上下文和导出，迟到的语音定稿也不会让它重新出现。
- 中文（含英文术语）只输出中文。英文按「英文原题 → 题目中文译文 → 英文回答逐句中文注释」显示。每句英文下方紧跟较小字号的中文含义，不再整段英文后另放整段翻译。自动判断错误时切换语言选择框后重答。导出文本保留EN:/ZH:逐句对应。
- 英文回答默认采用简单日常口语：优先常见词、主动语态和短句，每句通常8—15词，尽量不超过20词；必要专业术语保留。重新生成和展开回答同样遵循此规则。英文原题不简写，中文逐句注释保持完整。该约束通过提示词传给模型，不是词汇过滤器。
- 耳机拔出、音频设备变化、识别断线时暂停，转写缺口会提示；检查设备后重新开始。失败期间不缓存原始音频。
- 回答优先给出能直接口头表达的完整内容：技术题讲原理和取舍，情境题讲具体处理步骤，经历题优先结合个人背景中的项目或工作经历讲清行动、结果与收获。资料中的待确认备注不读进答案，缺少数字时可用功能结果；通用知识和条件推演可充分展开，个人履历和成果数字以资料为据。历史参考建议不是新增经历，旧回答中的保守措辞不沿用。
- 日常工作生活、学习、协作、沟通、压力和时间安排等行为经历题，缺少合适素材时允许生成符合人物画像的虚构参考故事，用第一人称讲完整起因、行动、结果与收获，追问时保持同一故事的细节一致。故事不写入个人背景；正式履历、核心项目职责和成果数字仍以资料为据，不构造未在资料中提及的企业任职或专业资质。这些规则同时适用于中英文、重新生成和展开回答，通过提示词约束模型。
- 「导出本次记录」导出纯文本。关闭窗口结束会话；音频不保存，会话默认不落盘。

## 本地数据

配置保存在 Electron `app.getPath('userData')` 下的 `settings.json`（Windows 通常为 `%APPDATA%/interview-desk`）。密钥通过 Electron `safeStorage` / Windows DPAPI 加密，个人资料以普通本地文本保存；只有设置页提交新密钥时短暂经过页面，保存后不会从主进程返回密钥。

音频送到百炼，问题、个人资料与最近五轮已完成参考答案送到 DeepSeek。关闭窗口或暂停监听会释放采集流及转写连接。

## 验证

```powershell
npm test
npm run smoke
npm run smoke:audio
npm run smoke:mic
npm run smoke:layout
npm run smoke:instance
```

自动化测试涵盖语种规则、重复转写/提交、长问题合并、UTF-8 SSE 分片、断流、取消、接口错误、配置保存和 ASR 时序/积压。

`smoke` 启动隐藏 Electron 窗口，检查 preload 桥接、设置弹窗及页面，截图保存到 `artifacts/smoke.png`，使用单独的临时配置目录，不调用真实服务。

`smoke:audio` 额外短暂申请本机系统音频回环并运行 AudioWorklet，确认有音频轨道和 PCM 数据块后立即释放；不保存或上传声音。界面测试中的回答为本地模拟内容，不能视为真实服务验收。

`smoke:mic` 短暂打开默认麦克风，验证纯音频 PCM、无需 API 的本地音量、来源保存、切换释放及拒绝授权后的恢复；不保存或上传声音。需要 Windows 允许桌面应用使用麦克风，未通过时不得视为真实麦克风链路已验证。

`smoke:layout` 检查1160×820、980×680、760×600下的输入/输出可用空间、页面溢出及按钮可见性，并在 `artifacts/layout-宽x高.png` 保存示例界面截图，不调用真实服务。

真实服务验收：参照 `test/manual-checklist.md`，各测试至少 5 道中文/英文题，记录首段耗时及识别错误。无真实凭证时这部分为 **未验证**，模拟测试不能证明耳机采集、真实识别质量或服务延迟。

## 排错

- 无法连接 DeepSeek：检查密钥、余额、模型 ID 与网络；401/403 为鉴权，429 可能是限流或额度。
- 无法连接百炼：检查 Workspace ID、地域、密钥、模型开通状态。
- 没有音量：检查默认播放设备并播放声音；设备切换后重新监听。部分设备/驱动的回环兼容性需实机确认。
- 连接提前结束或超时：已显示内容保留，手动重试；网络积压时会暂停而非重放旧音频。

## 结构

`src/main.js` 管理主进程、权限和生命周期；`src/smoke.js` 独立承接界面与能力冒烟测试；`preload.js` 暴露有限桥接；`state.js` 管理问题；`answer.js`/`asr.js` 对接服务；`config.js` 保存配置；`src/ui` 为静态界面与 AudioWorklet。页面不开启 Node 集成，不加载外部网页。
